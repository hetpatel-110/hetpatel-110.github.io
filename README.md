## Website stack

HTML, CSS, and JavaScript. No build step or external font dependencies. The responsive layout includes résumé and contact links, expandable additional projects, and an interactive CPU scheduling example.

## Run locally

Open `index.html` in a browser, or run `python3 -m http.server 8000` in this folder and visit `http://localhost:8000`.

## Hosting

Published through GitHub Pages from the `main` branch and repository root. `.nojekyll` keeps the site as plain static files.

## Updates

- Edit content in `index.html`.
- Update styling in `styles.css`.
- Update the scheduling example in `script.js`.
- Replace `assets/Het_Patel_Resume.pdf` when the résumé changes.

GitHub Pages publishes changes after they are committed to the publishing branch.
